# BaruasWeb

BaruasWeb is a team-built engineering project that starts as a static website and evolves into a secure, NAS‑integrated web platform for internal tools and experimentation.

## Purpose
- Build a real-world collaboration environment
- Practice software, networking, and security workflows
- Create a portfolio-grade project

## Project Stages

### Early Stage — Static Web
- Academic tracker (schedule, CGPA, assignments)
- Network health tracker (router/server/DNS ping)
- House budget tracker
- Responsive for mobile & PC

### Mid Stage — Dynamic Web
- User authentication
- Improved UI/UX
- NAS file access (“Dropbox”-style)
- Companion features

### Final Stage — Secure External Access
- Accessible outside LAN
- Encrypted (HTTPS)
- Security-first architecture

## Team Roles
- Infra / Network
- Software Development
- Cybersecurity
